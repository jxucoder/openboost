## Objective/tree construction

Public squared geometry and depthwise tree functions keep bulk work resident.
Trees copy callback leaf values and own their packed inference buffers; they do
not retain training data lifetimes. Scoped scratch releases intermediate records
and preserves preexisting caller inputs. Supplied legality cannot create an
empty-child tree, while its objective policy remains independently replaceable.
DeviceData now records fitted-binning identity separately from problem/data
identity. Validation data must reuse the exact training cuts, not merely bin counts.
Default full-row positions are generated by a CUDA kernel, removing a per-tree
host row-index upload. Host control still uploads final topology explicitly.

Forty-two real-device verifiers collect, covering the frozen first-round matrix,
callback replacement/ownership, cleanup failures and CPU inference export. This
is pending implementation validation, not an addition to the 88 passing T4 cases.
Full CPU regression passes 1232 tests with one Linux-only skip and 130 GPU cases
deselected. Production/changed-test Ruff and documentation build pass. Imports
also succeed with CUDA packages blocked. No hardware test was run for this slice.

## Risks and Follow-ups

Explicit release, borrowed inputs, model sharing and failed allocations must not
invalidate accepted state. A frozen dataclass alone does not provide this guarantee.
Retained user snapshots have a real storage cost; default history must avoid O(T*N)
raw arrays. Device training and formal R/C/A/E acceptance remain unverified.
