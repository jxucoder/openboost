# Exploratory author packet preparation

This packet is not dispatched. D1/D2 cards preserve the public development task
semantics. The OpenBoost author receives only these cards, selected current v1
documentation and an installed wheel. Existing example solutions and evaluator
oracles are not included. Public implementation inside the wheel is available
for inspection; useful existing public operations are legitimate tools.

Budget per attempt: 1800 seconds and 20000 generated tokens. The runner must
observe and enforce both, recording setup, active/blocked time, hints, failures,
private/core edits and first correct result. Missing measurements do not count
as zero. Actual filesystem/container isolation must be tested before dispatch.
No model/settings, incumbent arm or independent runner is frozen yet. Therefore
this preparation cannot support a comparative author-cost result or formal E5.
