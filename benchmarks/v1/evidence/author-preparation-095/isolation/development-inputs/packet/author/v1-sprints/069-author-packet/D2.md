# D2: Cohort-constrained split selection

Implement a public OpenBoost learner extension that selects the highest ordinary
Newton gain among feasible splits. Every child must contain at least one unit of
each declared cohort information column. Information is finite, nonnegative,
aligned with original rows and independent of objective training weights. Preserve
the existing gain, regularization and tie policy. If no positive-gain feasible
split exists, retain a leaf. Cohort information is not a predictor feature.

Use the installed wheel and public components, without core edits or private
imports. Deliver extension source, a runnable two-round composition, commands and
a saved model that replays without the extension installed. Preserve problem/row
identity and reject misaligned information. Report any interface obstacle.

The evaluator independently enumerates candidates, including six fixed-bin rows
with alternating A/B cohorts, g=[-6,1,1,1,1,2], h=1 and lambda=1. It checks that an
unconstrained winning split can be infeasible; all-A-left/all-B-right can prohibit
splitting. Zero objective weights must not erase independent cohort information.
Tie behavior, a second round and persisted inference also matter.

Do not supply invented timing or token counts. This is a known development task,
not a held-out task. A mathematically equivalent public-component solution is valid.
