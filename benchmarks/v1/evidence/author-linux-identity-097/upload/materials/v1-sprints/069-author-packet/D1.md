# D1: Expectile objective control

Implement a public OpenBoost extension for tau=0.8 expectile regression. With
r=y-F, loss is abs(tau-I[r<0])*r^2. Supply analytic gradient/curvature, a weighted
initial constant and two boosting rounds. At r=0 use gradient zero and curvature
2*tau. Preserve offsets and apply training weights exactly once. Zero-weight rows
must not determine the optimum. Tau=0.5 reduces to symmetric squared loss.

Use an installed OpenBoost wheel and public components. Submit runnable extension
source, commands and a saved model that replays in a fresh process without the
extension installed. Record unsupported cases explicitly. Do not edit the core or
import private names. Report any boundary that prevents a correct implementation.

The evaluator checks mixed residual signs, zero residuals/weights, weighted base,
two-round raw state and persisted predictions against independent mathematics.
Do not supply invented timing or token counts; the execution recorder owns those.
This is a development control, not a held-out task or an assumed OpenBoost win.
